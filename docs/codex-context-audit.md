## 共用上下文修复与委派复用

适用范围为所有经过 AgentManager 启动/恢复的 Provider，包括 Claude、Codex、OpenCode、自定义角色及 Cursor/通用 ACP。共用阅读约束在启动时组合到运行配置，不写回用户的角色提示；原有独立判断、交叉复核与风控要求优先保留。ACP 没有通用 system-prompt 配置入口，因此在恢复/创建后的首次 prompt 携带运行说明，后续轮次不反复追加。

- `read_context_file` 是所有可使用 Paseo MCP 的 Agent 共用工具：读取范围、字段投影和额度见上节。返回续读位置与截断标志，重要证据不能因截断而略过。
- 相同 Agent 对同一未变化的选区重复读取时返回短提示，不重复正文。内容变化自动重新返回；压缩后需要重新阅读时用 `force`。缓存有界且不持久化正文，不跨 Agent 共用。
- 共用提示要求先定位章节、再读必需范围；只取快照相关字段/记录，向复核方发送证据路径与紧凑差异。原生 shell/web 工具由各 Provider 执行，这个工具的字符上限不是所有工具的统一 token 硬上限。
- Codex 配置只通过 `thread/start` / `thread/resume` 发送；移除 `turn/start` 不支持的 `config` / `developerInstructions`。每次新连接第一次恢复时，即便原生线程已加载，也执行配置恢复；同一连接后续轮次不重复恢复。保留默认 4000 的原生工具结果预算，但不声称所有 Codex 工具都受该预算控制。
- Agent-scoped MCP `create_agent` 接受 `taskId`、`role`，按父会话、工作区、任务、角色查找未归档子会话。并发调用在同一 daemon 内串行查找/创建，匹配标签持久化，支持重连后的查找。返回 `reused: true` 时不重复发送 initialPrompt；继续工作使用 `send_agent_prompt`。模型/设置不匹配明确报错，不能悄悄切换模型。
- 旧调用不传 taskId 时只对相同初始提示去重，不按标题猜测任务。已有无标识的历史会话继续通过已知 Agent ID 发送，不自动合并。CLI 的普通 `run` 仍为显式新建；需要保证复用的模型委派使用上述 MCP 路径。新快照的独立复核使用新的 taskId，避免把已经看到主方结论的旧上下文当作独立判断。

验证覆盖字段投影、重复读取/内容变化、分页、路径越界、并发跨 MCP 连接返回同一 Agent 且只启动一次提示、配置冲突、任务隔离、失败锁释放、ACP 首次传递与 Codex 已加载线程恢复。通过定向测试、服务端类型检查、lint、构建；没有调用收费模型重复执行持仓分析。原生无模型探针不能恢复尚未产生 rollout 的空线程，未把该探针当成真实 token 节省验证；收益需下一次实际工作流对照。

- 11 个样本中有 3 个记录到压缩，共 4 次。一个样本在 210 次用量事件中压缩 2 次，工具输出 JSONL 累计约 1115107 字符；另一个 143 次事件、1 次压缩，工具输出约 1041678 字符。事件不是用户轮次，JSONL 字符也不是 token 或实际保留上下文。
- 检查长回包发现多文件整篇读取、重复读取工作流/AGENTS、长 JSON 与日志；单个序列化回包可超过 60000 字符。这是可优化的上下文增长来源，不能证明它是所有用户会话的唯一原因。
- Codex Desktop 的长任务也有压缩记录；现有样本不是同模型、同任务、同工具结果的严格 A/B，不能断言某客户端永不压缩。
- Paseo 的 Codex adapter 按 thread ID 恢复原生历史；turn/start 只构造本次新增输入，没有将 UI timeline 整份重新作为用户输入发送。新回归测试验证一次提交只发送一次新增输入。

## Lite.4 改动

- 仅在 Paseo Codex adapter 的会话配置中默认设置 `tool_output_token_limit: 4000`；创建、恢复与后续请求使用同一配置生成逻辑。未改用户全局 Codex 配置、模型窗口或压缩阈值。显式 customCodexConfig 仍可覆盖该默认值。
- 增加简短上下文使用约束：搜索定位后读取相关范围、一般先以约 2000 输出 token 读取、避免重复读取未变文档、对被截断的重要证据继续定向读取；保留角色职责及独立/交叉复核。
- 不删历史，不降低思考级别，不关闭自动压缩，不改正式小巴小保流程。
- 官方配置参考明确 `tool_output_token_limit` 控制单个工具结果存入历史的 token 预算：https://learn.chatgpt.com/docs/config-file/config-reference 。具体模型/tool 实现的实际截断与收益还需在更新后的问题会话观察，不能用原始 rollout 文件大小反推节省比例。

## 生效与验证

旧会话已有的大量上下文不会即时缩小；新预算主要限制后续输出。WSL 必须切换新版 daemon；对已经加载的原生线程，仅重载 Paseo provider 不足以证明配置生效，须完成上面的协议缺口验证。手机仍使用原版 App，远端行为由 daemon 决定。

客户端同时增加 Alt+Enter 光标处换行，优先于补全选择和发送处理；IME 组合输入仍先交给输入法。保留 Shift+Enter 兼容，Enter 与 Ctrl/Command+Enter 行为不变。
