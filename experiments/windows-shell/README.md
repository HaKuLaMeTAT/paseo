# Windows shell experiment

Read [the evaluation and its limits](../../docs/windows-desktop-evaluation.md) before running this experiment.
The agreed product changes live in [the customization plan](../../docs/customization-plan.md).

`run.ps1` compiles the isolated WebView2 window and samples it alongside Electron on Windows.
`audit.py` refreshes the source inventory; `summarize.py` aggregates a completed batch.
This directory is an experiment, not a replacement desktop distribution.
